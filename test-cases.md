# Тест-кейсы для API

В этом документе описаны позитивные тест-кейсы, автоматизированные для проверки API.

| ID      | Название                                                  | Приоритет | Шаги выполнения                                                                                                                                                            | Ожидаемый результат                                                                                                                                      | Примечания                                                                                                                                                                   |
| :------ | :-------------------------------------------------------- | :-------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TC-01** | Создание и последующее получение сущности                  | High      | 1. Отправить POST-запрос на `/create` с валидным телом.<br>2. Сохранить `id` созданной сущности.<br>3. Отправить GET-запрос на `/get/{id}` с полученным `id`.                   | 1. POST-запрос возвращает статус-код `200` и `id > 0`.<br>2. GET-запрос возвращает статус-код `200` и тело ответа, полностью соответствующее отправленным данным. | -                                                                                                                                                                            |
| **TC-02** | Получение списка всех сущностей                           | High      | 1. Отправить GET-запрос на `/getAll`.                                                                                                                                      | 1. Запрос возвращает статус-код `200`.<br>2. Тело ответа содержит JSON-объект с ключом `entity`, значение которого — список (может быть пустым).            | -                                                                                                                                                                            |
| **TC-03** | Обновление существующей сущности                          | High      | 1. Создать новую сущность (предусловие).<br>2. Отправить PATCH-запрос на `/patch/{id}` с новыми данными.<br>3. Отправить GET-запрос на `/get/{id}` для проверки изменений. | 1. PATCH-запрос возвращает статус-код `204`.<br>2. Последующий GET-запрос возвращает обновленные данные сущности.                                        | -                                                                                                                                                                            |
| **TC-04** | Удаление существующей сущности                            | High      | 1. Создать новую сущность (предусловие).<br>2. Отправить DELETE-запрос на `/delete/{id}`.<br>3. Отправить GET-запрос на `/get/{id}` для проверки удаления.                  | 1. DELETE-запрос возвращает статус-код `204`.<br>2. Последующий GET-запрос возвращает код ошибки клиента (например, `404 Not Found`).                      | **Обнаружен баг:** API возвращает `500` вместо `404` на шаге 3. Автотест адаптирован и проверяет, что статус-код `>= 400`.                                                 |
| **TC-05** | Фильтрация списка сущностей по параметру `verified=true` | High      | 1. Создать две сущности: одну с `verified=true`, другую с `verified=false`.<br>2. Отправить GET-запрос на `/getAll` с query-параметром `?verified=true`.                  | 1. Запрос возвращает статус-код `200`.<br>2. Список `entity` в ответе содержит только сущности, у которых поле `verified` имеет значение `true`.             | -                                                                                                                                                                            |
